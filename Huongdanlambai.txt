1. LÀM CÂU 1 (Q1 - WEB API)
--------------------------------------------------------------------------------
Bước 1.1: Cấu hình Q1/appsettings.json
  - Sang VS mẫu copy toàn bộ nội dung Q1/appsettings.json dán đè vào Q1/appsettings.json bài thi.
  - Chuỗi kết nối chuẩn của bạn trong appsettings.json:
    "MyCnn": "Server=localhost;Database=PRN232_PE_SU26_13;uid=sa;pwd=123;TrustServerCertificate=True;"
  - Nếu đề đổi tên Database (hoặc máy thi dùng Server name khác): sửa lại cho khớp bước 0.1 -> Ctrl + S.
  - (KHÔNG đổi tên key "MyCnn", KHÔNG thêm JSON lạ như Kestrel/Endpoints).

Bước 1.2: Tự động sinh thư mục Models (Scaffold Database)
  - Trên VS bài thi: Menu Tools -> NuGet Package Manager -> Package Manager Console.
  - Kiểm tra ô "Default project" ở trên khung console phải đang chọn là "Q1".
  - Chạy LỆNH 1 (KHUYÊN DÙNG - tự đọc tên DB từ appsettings.json, trường đổi tên DB không cần sửa lệnh):
    (Nhớ bấm Ctrl + S lưu file appsettings.json ở Bước 1.1 trước khi chạy)
    dotnet ef dbcontext scaffold "Name=ConnectionStrings:MyCnn" Microsoft.EntityFrameworkCore.SqlServer -o Models --project Q1 --no-onconfiguring --force
  - Hoặc chạy LỆNH 2 (trực tiếp — nếu trường đổi tên DB thì nhớ sửa tên sau chữ Database= ngay trong lệnh; BẮT BUỘC giữ --no-onconfiguring để không bị hardcode vào file Context gây 0 điểm):
    dotnet ef dbcontext scaffold "Server=localhost;Database=PRN232_PE_SU26_13;uid=sa;pwd=123;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -o Models --project Q1 --no-onconfiguring --force
  - (Nếu máy báo chưa có dotnet-ef thì chạy trước: dotnet tool install --global dotnet-ef)
  - Chú ý: Copy ĐỦ CẢ DÒNG bắt đầu từ chữ "dotnet ef...".
  - Chờ 2-3 giây sau khi hiện Build succeeded cho đến khi dấu nháy PM> hiện lại.
  - Nếu bên Solution Explorer chưa thấy hiện thư mục Models -> bấm nút Refresh (biểu tượng 2 mũi tên xoay vòng trên thanh Solution Explorer) -> xem tên file *Context.cs.

Bước 1.3: Cấu hình Q1/Program.cs
  - Sang VS mẫu copy toàn bộ Q1/Program.cs dán đè vào Q1/Program.cs bài thi.
  - Sửa tên *Context cho khớp với tên file vừa sinh ra ở Bước 1.2 -> Ctrl + S.

Bước 1.4: Tạo Controller cho Q1
  - Chuột phải vào project Q1 -> Add -> New Folder -> đặt tên: Controllers
  - Chuột phải vào Controllers -> Add -> Class... -> đặt tên: GymController.cs (Q1-A) hoặc PackagesController.cs (Q1-B).
  - Sang VS mẫu copy toàn bộ file Controller tương ứng dán đè vào.
  - Nếu đề đổi bảng/thuộc tính: sửa theo các dòng ghi chú [NẾU ĐỔI ĐỀ - SỬA Ở ĐÂY] trong file vừa dán
    (đổi tên *Context, tên route [HttpGet/Post/Delete], tên field JSON, và câu báo lỗi 400).

Bước 1.5: Chạy test Q1
  - Chuột phải vào Q1 -> Set as Startup Project -> bấm F5 test các API trên Swagger.
  - Xong thì bấm nút Stop (hình vuông đỏ) trên Visual Studio.

2. LÀM CÂU 2 (Q2 - WEB MVC GỌI GIVEN API)
--------------------------------------------------------------------------------

Bước 2.2: Nhận diện tên Controller của Q2

  - Chuột phải vào project Q2 -> Add -> New Folder -> đặt tên: Controllers

4. XÓA CACHE ẢO VISUAL STUDIO NẾU BỊ BÁO ĐỎ HÀNG TRĂM LỖI
--------------------------------------------------------------------------------
Nếu VS báo đỏ vô lý (CS0234, CS0518, System.Object not found):
- Tắt Visual Studio.
- Mở PowerShell tại thư mục chứa file .sln chạy lần lượt 3 lệnh:
  Get-ChildItem -Force -Recurse -Filter ".vs" | Remove-Item -Force -Recurse
  Get-ChildItem -Force -Recurse -Include "bin","obj" | Remove-Item -Force -Recurse
  dotnet build
- Mở lại Visual Studio.
